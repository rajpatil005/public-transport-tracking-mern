# 🚌 Public Transport Tracking System (MERN)

> A Smart Public Transport Tracking System developed using the MERN Stack that allows users to track buses in real time, check schedules, find nearby bus stops, and book tickets easily.

---

## 📌 Project Overview

Public Transport Tracking System is a full-stack web application developed to improve the public transportation experience for passengers.

The system provides live bus tracking, route information, nearby bus stops, ticket booking, schedules, and an interactive map interface.

This project was developed as a Smart India Hackathon (SIH 2025) idea under the Transportation & Logistics theme.

---

## ✨ Key Features

- 🚍 Real-Time Bus Tracking
- 🗺️ Interactive Leaflet Map
- 📍 Nearby Bus Stops
- 🚌 Live Route Information
- 📅 Bus Schedule
- 🎫 Online Ticket Booking
- 🔍 Route Search
- 👨‍💼 Admin Dashboard
- 📱 Responsive Design
- ⚡ Fast MERN Architecture
